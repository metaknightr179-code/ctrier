\begin{itemize}
    \item \textbf{KuaiRec}~\cite{gao2022kuairec} is a large-scale real-world video recommendation dataset. The dataset contains 10,728 unique items across 31 semantic categories. Following standard sequential recommendation protocols, we constructed four dataset variants based on different item selection strategies for the training/validation/test split: \emph{highest\_individual}, \emph{highest\_average}, \emph{first\_individual}, and \emph{first\_average}. For each variant, we adopted the leave-one-out evaluation protocol~\cite{hidasi2016session,kang2018self,sun2019bert4rec}: the last item in each user's interaction sequence was designated as the test item, the second-to-last item for validation, and the remaining items for training. All sequences were truncated to a maximum length of 50 items.
    \item \textbf{MovieLens-1M (ML1M)}~\cite{harper2015} is a classic movie rating dataset. We treat ratings of at least 4 stars as positive feedback and apply iterative 5-core filtering on users and items. Movies are described by 18 multi-label genres that serve as categories.
    \item \textbf{MicroLens}~\cite{ni2023microlens} is a content-driven micro-video recommendation dataset with rich per-video category metadata. We retain interactions whose watch-time-to-duration ratio is at least 0.1 and deduplicate user--video pairs, keeping the highest-ratio engagement. Videos are organized into 57 content categories.
    \item \textbf{KuaiRand-1K}~\cite{gao2022kuairand} is an unbiased short-video recommendation log collected under randomized exposure. We keep only fully watched (\emph{long-view}) interactions, deduplicate user--video pairs, retain the 20,000 most popular videos, and apply iterative 5-core filtering. Videos carry 44 content tags.
\end{itemize}

For all datasets, items are re-indexed to $1,\ldots,|\mathcal{I}|$ with $0$ reserved for padding, and interactions are grouped by user and sorted chronologically. The three additional datasets use the same leave-one-out split and 50-item truncation as the KuaiRec variants.

\subsubsection{Evaluation Protocol}
We evaluate all models by ranking the held-out item against the \emph{entire item set} without sampled negatives, avoiding the inconsistencies of sampled metrics~\cite{krichene2020sampled}. We report accuracy metrics Recall@$k$ (Hit Ratio), NDCG@$k$, and MRR@$k$; diversity metrics Intra-List Distance (ILD@$k$)~\cite{ziegler2005} and Category Coverage (CC@$k$)~\cite{adomavicius2012}; and the Consecutive Similarity (CS@$k$) of adjacent list items, for $k\in\{5,10,20\}$. ILD is the average pairwise Euclidean distance between L2-normalized item vectors, CC the fraction of categories covered by the list, and CS the average cosine similarity between items at consecutive positions (lower CS means locally less repetitive lists). Crucially, ILD and CS are measured for \emph{all} models in the same frozen, pretrained content-embedding space (the dataset-specific category/item2vec vectors released with the data), so cross-model diversity numbers are directly comparable.

\subsubsection{Model Configuration}
To evaluate all models, we adopted the widely used leave-one-out protocol for sequential recommendation: for each user, we used the last item as the test item, the second-to-last item for validation, and the remaining items for training. As discussed above, evaluating with sampled negatives can introduce inconsistencies compared with non-sampled counterparts~\cite{krichene2020sampled}; we therefore evaluated every method on the entire item set without sampling, using identical splits across models. We implemented all models in PyTorch and set the hyper-parameters of each baseline according to the suggestions provided in its original paper, reporting the performance of each baseline under its optimal settings.

Regarding our PACER method, we initialized all parameters with a zero-mean Gaussian of standard deviation $0.02$. The embedding size was set to 64, and all linear mapping functions shared the same hidden size. Both the RT and PT transformers consisted of 2 layers with 2 attention heads, and we applied a dropout rate of 0.5 on the embedding matrix and the transformer module. For optimization, we used the Adam optimizer~\cite{kingma2015} with a learning rate of $0.001$ and a batch size of 256. We trained the model with early stopping based on its performance on the validation set (patience of 100 epochs and a minimum improvement of $10^{-4}$), for at most 1{,}000 epochs; the RT model was trained first to convergence and its parameters were frozen while training the PT model. The diversity trade-off $\lambda$ in Equation~\eqref{eq:gen_score} was set to 0.1 following~\cite{shi2024trier}, and the position-aware penalty weight $\lambda_c$ to 0.01. The number of retrospectively augmented items ($K$) was set to 5 and the number of augmented sequences, i.e., the beam width ($M$), to 3. For a fair comparison with previous studies, we set the maximum sequence length to 50 on all datasets. Consistent with prior research, we report Recall, NDCG, MRR, ILD, CC, and CS at $k \in \{5,10,20\}$.

\subsubsection{Baselines}
We compare with representative sequential recommendation methods, grouped into (i) vanilla sequential recommenders, (ii) self-supervised sequential recommenders, and (iii) diversified sequential recommenders.

\begin{itemize}
    \item \textbf{GRU4Rec}~\cite{hidasi2016session} is the pioneering recurrent approach to session-based recommendation. It embeds the item sequence into a stack of gated recurrent units (GRUs) that compresses the interaction history into a hidden state, which is then projected onto the item vocabulary to score candidates. We use one recurrent layer with embedding and hidden dimensions of 64 and dropout 0.2, trained with the standard next-item cross-entropy objective.
    \item \textbf{SASRec}~\cite{kang2018self} adapts the causal Transformer~\cite{vaswani2017} to sequential recommendation. It sums learned item and positional embeddings and applies a unidirectional self-attention mask so that each position can only attend to earlier items, predicting the next item at every sequence position in parallel. Following the original paper, we set the hidden size to 50 with 2 transformer blocks, 1 attention head, and dropout 0.5.
    \item \textbf{BERT4Rec}~\cite{sun2019bert4rec} replaces the causal mask with bidirectional self-attention and trains with a Cloze-style masked-item objective: a random subset of items (20\%) is replaced with a mask token and the model reconstructs them jointly using context from both sides, which strengthens contextual sequence modeling. We use a hidden size of 64, 2 transformer blocks, 2 attention heads, and dropout 0.2; masked training is converted to full-catalog next-item scoring at test time.
    \item \textbf{DuoRec}~\cite{wang2022duorec} is a self-supervised sequential recommender built on the same causal transformer backbone as SASRec. It regularizes representation learning with a contrastive loss between two views of a sequence: model-level augmentation obtained through stochastic dropout and \emph{supervised} positive pairs formed from sequences whose next target item is identical, which mitigates representation collapse. It is also the exact backbone architecture of our PT module ($d=64$, 2 layers, 2 heads), making it a clean reference for the effect of retrospective augmentation and diversity promotion.
    \item \textbf{TRIER}~\cite{shi2024trier} is the diversified sequential recommender most closely related to PACER and the foundation this work builds on. Its retrospective transformer (RT) processes the reversed interaction sequence and is trained with next-token prediction to hallucinate plausible items that could have preceded the observed history; beam search at inference yields $M$ augmented sequences, each interpreted as one of the user's latent intents. The prospective transformer (PT) then scores items by combining relevance with a diversity-promoting term that reserves probability mass for intents not yet covered by the current list, so diversity is optimized during list generation rather than by post-hoc re-ranking. We run the official implementation under our unified data splits and full-catalog ranking protocol, using plain item-ID embeddings and disabling content fusion, dense next-item supervision, and the position-aware consecutive penalty; any improvement of PACER over this configuration therefore isolates the contribution of our extensions.
\end{itemize}

\subsubsection{Ablation Variants}
To disentangle the contributions of PACER's components, we additionally report: (i)~\textbf{PT-no-consec}, which keeps the intent-coverage loss ($\lambda=0.1$) but disables the consecutive-similarity penalty ($\lambda_c=0$), testing whether local position-aware smoothing is needed on top of global intent coverage; (ii)~\textbf{PACER-full}, with both losses enabled at $\lambda=0.1$, $\lambda_c=0.01$; and (iii)~\textbf{RT-only}, the retrospective model evaluated alone for next-item prediction, assessing the standalone value of reverse trajectory modeling.
