# Protocol:
#   - All models were TRAINED on big-matrix-derived data (KuaiRec_variants/<variant>/)
#     and are evaluated here, WITHOUT retraining, on leave-last-out TEST splits built
#     from KuaiRec small_matrix.csv via convert_kuairec_to_yelp.py
#     (--interaction_file small_matrix.csv --min_watch_ratio 0.1, per-variant dedup /
#     average-watch-ratio options). Splits: ./KuaiRec_small_eval/<variant>/.
#   - 1411 test users; full ranking over 10728 items (raw video_id space, same as
#     training); item vectors for ILD/CS = KuaiRec_variants/kuairec_vec.npy.
#     recall@20_f / ndcg@20_f are the full-ranking (leave-last-out) metrics.
#   - TRIER-PT: greedy inference with fixed retrospective RT (save_rt_fix_<variant>),
#     invocation mirrors eval_greedy_fixrt.sh; -div/-lamb flags replicate each
#     checkpoint's training config (nodiv: lamb=0 no div loss).
#     Note: save_pt_fixrt_lamb0005 exists only for highest_individual / highest_average.
#   - GRU4Rec: per-variant gru4rec_best.pth via gru4rec_pytorch.py --eval_only.
#   - SASRec: shared sasrec_best.pth via sasrec_pytorch.py --eval_only (recall/MRR/NDCG);
#     ILD@20/CS@20 from eval_sasrec_ild_cs_small.py (identical top-20 lists per variant).
#   - Data note: 181,992 small_matrix rows have an empty timestamp (also empty
#     time/date); the converter falls back to timestamp=0.0 so they sort earliest.
#     Dedup strategy does not change the small-matrix item sets (no duplicate
#     user-video pairs); individual vs average watch-ratio filtering differ only in
#     the tie-broken ordering of equal-timestamp items (last-50 eval window identical).
#   - Skipped: save_pt_notype_fixrt_* was NOT evaluated - it is a duplicate artifact
#     (nested copies of the save_pt_fixrt_* checkpoints, identical md5), not a
#     distinct model.
#
